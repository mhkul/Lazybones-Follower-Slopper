Lazybones Follower Slopper 0.1.1 — Windows x64

Create a follower install ZIP from a Skyrim save and matching RaceMenu head
export. Extract outside game, mod and input folders. Open the EXE directly
for physical/deployed Data, or register it in MO2 with empty Arguments and
Run through the intended existing profile. Python and .NET are bundled.
Choose the Skyrim folder if direct-launch discovery needs help.

Choose the save and head NIF, then Continue. Confirm matching co-save, tint
DDS and JSlot when requested; Change RaceMenu preset replaces a bad automatic
match. Review Basic/Advanced settings, race/equipment choices, individual
asset packaging and sharing responsibility. Select applicable BodySlide build
and/or OBody NG (as-is) outputs. One produces a plain ZIP; both produce a FOMOD.
Save ZIP to selects
the delivery folder. Show ZIP in folder selects the finished ZIP. Cancel and
wait; failed delivery can retry without rebuilding. Earlier ZIPs remain.

Install the generated ZIP with your mod manager and read its dependency
instructions. Use MO2 Replace when switching variants. OBody/PDA and RSV
rules need compatible installed facilities at runtime; the builder does not
install them or edit global OBody assignments. SMP and retained race/assets
can require the source runtime dependencies listed in the follower ZIP.

Only OBody-preset-affected meshes build through BodySlide; unaffected meshes and
base hands/feet remain as-is. OBody NG (as-is) uses winning installed meshes
with compatible morph files and applies the actual preset in game. Confirmed
non-OBody captures use installed meshes without BodySlide. Cached Heels Fix lift is
discarded; original footwear metadata is preserved. Existing race retains
its provider and packages no skeleton; custom race uses a supported private
copy. Body overlays remain deferred with warnings.

Requested equipment and available proved assets can be retained through
recoverable missing references with named warnings and safe original calls.
Textures, reflections, audio or behavior may differ; read Build details.
Indispensable generation inputs and invalid/unsafe structures still stop the
operation. No missing provider or replacement is invented. Omission history
stays in builder details/local results, rather than installer history.

Equipment/build Error report and Copy report remove identifying details by
default, using report-local aliases and retaining known error categories,
call sites, versions, counts, offsets, lengths and available stage/exit facts.
Unknown text and input fingerprints are withheld. Review before sharing;
numeric facts may still characterize a setup. Save diagnostic ZIP saves that
safe report by default. Include private files (not anonymized) is unchecked;
opt in to collect a compact current-attempt bundle, which can reveal paths,
character/mod names and settings. Share private bundles privately. There is
no automatic upload. Local actionable errors still name your selected inputs.
Build details, result JSON and owned logs may contain private identifiers;
share the Error report payload instead of treating raw work files as anonymous.

User manual testing passed on the current Skyrim SE 1.5.97/MO2 setup.
Other game/store/manager combinations,
including AE, VR and actual Vortex setups, are unverified. Versions are
informational; concrete source/format and output-protection checks apply.
This release is unsigned. No universal appearance/compatibility is claimed.

AGENT_GUIDE.md covers installation, GUI operation and source rebuilding.
Buildable source is in src/; see src/BUILD.txt. Attempts/logs stay under
LocalApplicationData/Lazybones Follower Slopper/Builds. Private runtime
extraction is automatic. Follow a cache error only for its named folder;
do not delete unrelated caches or change source mods to hide errors.
Recent diagnostics reopens compact build evidence and offers Save finished ZIP
for pending delivery. After stopped children and successful ZIP saving, bulky
owned copies and redundant internal packages are released. Failed/cancelled
builds keep bounded compact evidence. History is up to eight attempts, seven
days and 128 MiB, checked on startup and after builds. Active work, exports and
pending ZIP delivery stay protected.
Packages and retry inputs also survive an exit before pending state or the
main result is written. Unconfirmed packages are retained; automatic recovery
requires recorded final structural success. Verified external ZIP delivery,
not a missing pending flag, permits completed-package cleanup.
Stale new owned runtimes are reclaimed after seven days or beyond two inactive
caches/512 MiB (partial extraction
after one day) only with inactivity and
lease proof. Unknown legacy caches and .NET bootstrap extraction are retained.
