# Reporting a problem

Please report problems in the [project's GitHub Issues](https://github.com/mhkul/Lazybones-Follower-Slopper/issues). Use a short title that describes what went wrong, such as “Build stops during outfit preparation.” Issues and attachments are public.

A single report with the details below is the most useful starting point. Include what you know; a missing version number or log does not prevent you from reporting.

```text
Application version:
Skyrim version (if known):
Mod manager and launch method (MO2 or direct):
Selected output(s) and race option(s):
BodySlide version (if BodySlide ran):
What I did:
Where it stopped / exact error:
Expected result:
What happened instead:
Diagnostic ZIP attached? (yes/no; note any missing or empty files)
```

In the error window, choose **Save diagnostic ZIP** and attach the default export. It is designed to omit identifying details, but review the ZIP before posting because no report can guarantee that every identifying detail is removed. The app does not upload it automatically. **Copy report** is an alternative; review it for identifying details before pasting it into a public issue.

The ZIP has an optional, unchecked private-details choice. It can include paths, character or mod names, and settings. Leave it unchecked for a public issue. If maintainers need private information, agree on a private way to share it first; do not attach a private-details ZIP to a public issue.

Save the ZIP for the failed attempt promptly, before optional cleanup or replacing the build. If a file is missing or empty, mention that; there is no need to repeat the same failure to create another copy. When comparing attempts or output choices, identify which attempt and output each file belongs to. If the app cannot start, share a brief description, the error text or a focused screenshot, and how you launched it. In **v0.1.0 and earlier**, diagnostic ZIP export is unavailable; use the copied report or error text, reviewing and redacting identifying paths or installed content before posting.

For appearance or in-game behavior problems, an optional focused screenshot and the output you installed can help. Do not attach your whole AppData or build folders, complete mod list, save/co-save, original assets, private diagnostic exports, or memory dumps as an initial report. You do not need to disable mods, change load order, update tools, test every output variant, or upgrade Skyrim just to report an issue. You also do not need to find details already included in the ZIP.
